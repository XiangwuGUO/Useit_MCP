行1（跌水行）

G（渠底） = 原对应渠底 − 2.2（请用公式引用上游的 G 并减 2.2，示例如下）。

其它列（C~L）复制/复刻上游公式（但注意 G 已按上面方式修正）。

下游原有行（例如原来的 K0+250）通常无需删除，但在插入后需向下填充/复制公式以保持引用链一致。

定位规则：在表中找到 桩号列 B 等于上游桩号（例如 200 或 K0+200）的行号 r_up；插入点应为 r_up + 1。
