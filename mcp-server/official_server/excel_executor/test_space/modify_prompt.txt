## 规划与决策：

- 在第一次出现 J > 2 的连续区段之前的某行设置一个“接消力池”，执行修改比降。
- 在第一次出现 J < -0.5 的原第 15 行执行跌水操作。

## Excel 动态操作步骤：

### 修改比降

- **步骤 1**: (Offset=0) 选中 **A5**，输入 `"接消力池"`。
- **步骤 2**: (Offset=0) 选中 **K5**，输入 `0.005`。
- **步骤 3**: (Offset=0) 选中 **F5**，输入公式 `="1/"&ROUND(1/K5,0)`。
- **步骤 4**: (Offset=0) 选中 **K5** 复制；选中 **K5:K23**，粘贴。

### 添加跌水

- **步骤 5**: (Offset=0) 选中 **A15**，输入 `"跌水2.2"`。
- **步骤 6**: (Offset=0) 在 **第 16 行** 插入新行 → `Current_Offset := 1`。
- **步骤 7**: (Offset=1) 选中 **C16**，输入公式 `=C15+3`。
- **步骤 8**: (Offset=1) 选中 **G16**，输入公式 `=G15-2.2`。
- **步骤 9**: (Offset=1) 复制 **D15:F15, H15:K15** 到 **D16:F16, H16:K16**。
